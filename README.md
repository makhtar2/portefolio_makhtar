# Makhtar Portfolio

Ce projet est un portfolio moderne construit avec **Next.js 15**, **React 19** et **Tailwind CSS 4**. 

Le design est inspiré d'une boutique e-commerce premium pour offrir une expérience utilisateur haut de gamme et dynamique.

## 🚀 Technologies utilisées

- **Framework :** Next.js (App Router)
- **Styling :** Tailwind CSS
- **Animations :** Framer Motion
- **Icônes :** Lucide React

## 📂 Structure du Projet

- `app/` : Routes et pages (structure single-page avec ancres).
- `components/` : Composants UI réutilisables.
- `assets/` : Ressources statiques et configuration des données.
- `public/` : Images et fichiers statiques.
- `legacy/` : Sauvegarde des fichiers de l'ancien portfolio.

## 🛠 Installation

1. Installez les dépendances :
   ```bash
   npm install
   ```

2. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```

3. Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## 📝 Personnalisation

Les données des projets se trouvent dans `legacy/projects/projects.json` (pour l'instant). Pour mettre à jour vos projets, modifiez ce fichier ou déplacez-le vers un emplacement plus approprié comme `assets/data/projects.json`.
